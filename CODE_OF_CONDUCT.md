# Code of Conduct

## Our Standard

XSSentinel welcomes contributions from people with different backgrounds and levels of experience. Please keep discussions respectful, constructive, and focused on improving the project.

Examples of helpful behavior include:

- Assuming good intent and asking clarifying questions.
- Giving feedback about ideas and code rather than people.
- Sharing relevant context when reporting issues or proposing changes.
- Respecting different viewpoints and experiences.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, doxxing, and publishing private information without permission.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, and other contributions that violate this code of conduct. Serious or repeated violations may result in a temporary or permanent ban from project spaces.

Report concerns privately through the security contact described in [SECURITY.md](SECURITY.md), or contact a project maintainer through the repository when the report does not involve a security issue.
